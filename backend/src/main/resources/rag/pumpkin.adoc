== [RAG-ID: KABOCHA-BASE] 재배 기본 정보
*요약:* 단호박은 수확 후 후숙(큐어링)을 거쳐 저장·출하하는 구조가 중요한 작물로, 수확 시기 분산과 저장 관리 성패가 가격 방어의 핵심이다.

*주요 품종:*
- 단호박(밤호박)

*생육 특성:*
- 씨뿌림 → 수확까지 작형에 따라 약 4~5개월
- 수분·착과 후 수확까지 약 55~60일 소요
- 전국 재배 가능

== [RAG-ID: KABOCHA-CALENDAR] 재배 일정
*하우스·터널 조숙 재배(난지):*
- 씨뿌림: 2월
- 아주심기: 3~4월
- 수확: 6~7월

*노지 재배:*
- 씨뿌림: 3~4월
- 아주심기: 4~5월
- 수확: 7~8월

*억제재배(난지):*
- 씨뿌림: 7~8월
- 아주심기: 8~9월
- 수확: 11~12월

== [RAG-ID: KABOCHA-HARVEST-STORAGE] 수확 후 관리 / 저장
*요약:* 단호박은 수확 직후 출하보다 후숙과 저장을 전제로 한 관리 체계가 필수적이다.

*후숙(큐어링) 및 저장:*
- 후숙 기간: 수확 후 약 30일
  - 상처 코르크화 유도 및 품질 안정 목적
- 저장 가능 기간:
  - 후숙 완료 후 8~12℃ 저장 시 약 3개월 가능

*저장 유의사항:*
- 수확 후 반드시 큐어링(후숙) 후 저장
- 저장 중 온도·습도 변동 최소화 필요

*출하 가능 기간:*
- 노지 재배: 7~8월 중심
- 억제재배(난지): 11~12월 중심

== [RAG-ID: KABOCHA-PRICE-PATTERN] 계절별 가격 패턴 (최근 5년 평균, 대략)
- 6~8월:
  - 조숙 + 노지 수확 물량 집중
  - 공급 증가로 가격 하락 가능성 높음
- 11~12월:
  - 억제재배 수확 물량 중심
  - 가격 안정 또는 약세 경향
- 겨울~이른 봄(1~3월):
  - 신선 출하 공백
  - 저장·유통 물량 의존으로 가격 상승 가능성 높음

== [RAG-ID: KABOCHA-PRICE-FACTORS] 가격 변동 요인
- 기상 스트레스:
  - 고온 시 생장·비대 저하
  - 9℃ 이하 또는 35℃ 이상 시 화기 이상 발생 가능
- 특정 시기 출하 집중 여부
- 수확 후 후숙·저장 관리 성공 여부

== [RAG-ID: KABOCHA-SELL-STRATEGY] 판매 전략 권장
*요약:* 단호박은 성출하 시기를 피하고, 후숙·저장 체계를 통해 출하 시점을 조절하는 전략이 수익성에 유리하다.

- 여름 성출하 구간(7~8월):
  - 분산 수확·분산 출하 전제 전략 권장
- 가격 방어 전략:
  - 수확 → 후숙(30일) → 저장(8~12℃) 체계 구축이 핵심
- 출하 시점 조절:
  - 억제재배(11~12월 수확)로 성수기와 겹침 최소화
  - 저장 물량은 1~3월 고가 구간 출하 검토
