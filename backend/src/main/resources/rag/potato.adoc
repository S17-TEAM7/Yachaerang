== [RAG-ID: POTATO-BASE] 재배 기본 정보
*주요 품종:* 수미, 대지마, 남작
*품종별 생육기간:*
- 수미: 90-100일
- 대지마: 100-110일
*재배 가능 지역:* 전국 (고랭지/평지/남부 특성)

== [RAG-ID: POTATO-CALENDAR] 재배 일정
- 봄감자: 3월 파종 → 6-7월 수확
- 가을감자: 8월 파종 → 11월 수확
- 지역별 파종 적기: 제주 2월, 남부 3월 초, 중부 3월 중순

== [RAG-ID: POTATO-STORAGE] 수확 후 관리 / 저장
- 저장 가능 기간: 3-6개월
- 권장 조건: 2-4도, 습도 85-90%
- 유의사항: 싹 방지, 온도 관리
- 출하 가능 기간: 수확 직후 ~ 저장 후 다음해 봄

== [RAG-ID: POTATO-PRICE-PATTERN] 계절별 가격 패턴 (최근 5년 평균)
- 1-2월: 높음 (저장품 소진)
- 3-5월: 최고점 (단경기)
- 6-7월: 급락 (봄감자 출하)
- 8-10월: 소폭 상승
- 11-12월: 중간 (가을감자 출하)

== [RAG-ID: POTATO-PRICE-FACTORS] 가격 변동 요인
- 전년도 재배면적 증감
- 주요 생산지(강원, 제주) 작황
- 수입 물량
- 이상기후

== [RAG-ID: POTATO-SELL-STRATEGY] 판매 전략 권장
- 저장 가능하므로 3-5월 판매 유리
- 6-7월 출하는 가격 하락 위험
- 장기 저장 시 품질 관리 필수
