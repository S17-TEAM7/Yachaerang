== [RAG-ID: CARROT-BASE] 재배 기본 정보
*요약:* 당근은 품종별 생육기간 차이가 있으며 저장성이 좋아 저온저장을 활용한 분산 출하 전략이 수익에 유리하다.

*주요 품종(계열):*
- 일반당근: 원추형 / 원통형(H형)
- 미니당근
- 노랑당근
- 보라당근

*품종별 생육기간(수확까지):*
- 조생: 80~90일
- 중생: 90~100일
- 만생: 약 120일

*재배 가능 지역:*
- 전국

== [RAG-ID: CARROT-CALENDAR] 재배 일정
*촉성재배(시설):*
- 하우스: 11월 하순 파종
- 터널: 1월 중순 파종

*봄 재배(노지):*
- 3월 파종

*가을 재배(노지):*
- 중부: 7월 중순 파종
- 남부: 7월 하순 파종

== [RAG-ID: CARROT-HARVEST-STORAGE] 수확 후 관리 / 저장
*요약:* 당근은 0℃ 전후의 고습 조건을 유지하면 수개월 이상 저장이 가능하며, 가을 수확 물량은 저장을 통해 봄까지 분산 출하가 가능하다.

*저장 가능 기간 및 조건:*
- 저장 가능 기간: 0~1℃ 고습 조건이면 수개월 ~ 반년 이상 저장 가능
- 권장 저장 조건(근채류 기준):
- 온도: 0℃ 전후
- 습도: 90~95%

*저장 유의사항:*
- 저장 중 품질 유지를 위해 0℃·고습 유지가 핵심
- 저장 판매 시 에틸렌 분리(에틸렌 발생 품목과 분리 보관) 전제 권장

*출하 가능 기간(전략):*
- 가을당근:
- 수확 직후 일부 출하
- 일부는 저온 저장 후 봄까지 분산 출하

== [RAG-ID: CARROT-PRICE-PATTERN] 계절별 가격 패턴
- 10~11월: 물량 증가 → 가격 하락(약세) 경향
- 12~2월: 저장/겨울 물량 중심 → 보합~약세
- 3~5월: 저장재고 감소 + 봄작 수확 전 → 가격 상승 가능성
- 7~8월: 공급 증가 시 가격 하락 가능

== [RAG-ID: CARROT-PRICE-FACTORS] 가격 변동 요인
- 파종 시기 실패:
- 봄에 너무 이르면 저온 감응으로 꽃대(추대) 발생 위험
- 기상 영향:
- 고온·집중호우·건조 → 뿌리 비대/착색 불량, 병해 증가
- 재배 및 재고 요인:
- 재배면적 변화
- 저장재고량(저장 출하 물량) 변동

== [RAG-ID: CARROT-SELL-STRATEGY] 판매 전략 권장
*요약:* 당근은 가을 출하 구간의 약세를 피하고, 저온저장을 활용해 봄철 가격 상승 구간에 분산 출하하는 전략이 유리하다.

- 가을 출하(10~11월):
- 공급 증가로 가격 약세 위험이 큼
- 전량 즉시 출하보다는 저장 분산 전략 검토
- 분산 출하 전략:
- 저온저장 기반으로 3~5월 가격 상승 구간에 일부 물량 배분
- 저장 판매 전제:
- 0℃ 전후 유지
- 습도 90~95%
- 에틸렌 발생 품목과 분리 보관
